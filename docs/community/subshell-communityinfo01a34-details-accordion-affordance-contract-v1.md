# COMMUNITYINFO01A34 — details accordion affordance contract

Successor polish for COMMUNITYINFO01A33.

## Intent
- keep the structured About / Rules / Moderators tabs from A33
- keep About content available on demand
- make the `Community details` section obviously expandable
- reuse the visual language already established by rule rows and other tappable list content

## Required product behavior
1. The About tab still shows the public subreddit/community description immediately.
2. `Community details` remains collapsed by default.
3. The collapsed row is clearly tappable through shared app visuals:
   - list row styling
   - supporting copy
   - leading info icon
   - trailing expand/collapse chevron
4. Tapping the row expands/collapses the full markdown details.
5. Rules accordion and moderator identity/avatar behavior remain unchanged.
