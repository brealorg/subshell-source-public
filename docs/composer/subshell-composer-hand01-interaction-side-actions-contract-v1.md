# subshell COMPOSER-HAND-01 interaction-side actions contract v1

COMPOSER-HAND-01 applies the persisted Interaction side to thumb-oriented composer actions without mirroring editor content or semantic navigation.

## Follows Interaction side

- The Add image and Add GIF attachment cluster occupies the selected interaction edge in both post and comment composers.
- Markdown mode and preview actions occupy the opposite toolbar edge.
- Markdown formatting tools keep their canonical order in the flexible center strip.
- The removable media overlay uses the selected interaction corner.
- The fixed media-above-text placement from COMPOSER-04 is preserved.

## Fixed semantics

Semantic Back, Close, Cancel, Discard, Post, and replacement-dialog actions keep their logical Material positions.
The editor text direction, title and body fields, character counter, poll-row actions, rendered Markdown, IME handling, and safe-drawing behavior do not follow Interaction side.
